# RESTAURANTE LIVING TO EAT

## Objetivo
Crear una página web de forma colaborativa utilizando GitHub y sus herramientas de trabajo en equipo.

## Descripción del Proyecto
Living To Eat es una página web para un restaurante que permite visualizar información sobre el establecimiento, su menú de platos, promociones, reservas y datos de contacto. El proyecto fue desarrollado de manera colaborativa utilizando GitHub como herramienta de gestión y control de versiones.

## Funcionalidades
- Página principal del restaurante.
- Menú de especialidades.
- Sección de reservas.
- Sección de promociones.
- Información de contacto.
- Diseño responsivo para distintos dispositivos.

## Tecnologías Utilizadas
- HTML5
- CSS3
- GitHub

## Respuesta a la Pregunta Final

### ¿Cómo facilita GitHub el trabajo colaborativo en un proyecto de desarrollo de software?

GitHub facilita el trabajo colaborativo permitiendo que varios integrantes trabajen simultáneamente en diferentes ramas sin afectar el proyecto principal. Además, proporciona herramientas como Issues para organizar tareas, Commits para registrar cambios, Pull Requests para revisar el trabajo realizado y Merge para integrar las modificaciones aprobadas. Esto mejora la organización, la comunicación y el control de versiones dentro del equipo.
